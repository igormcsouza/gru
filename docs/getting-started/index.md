# Getting started

1. [Install](install.md) the skill, agents and tether (one command).
2. Follow the [Quickstart](quickstart.md): the first run interviews you, then runs your first feature.

Gru is global: it works in any project and keeps project facts in that project's `AGENTS.md`/`CLAUDE.md` and your preferences in the store's git-ignored `local.yml`.
